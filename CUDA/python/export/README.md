# export — CLIP ONNX export + golden reference tensors

Exports CLIP ViT-B/32's **vision encoder** to `out/model.onnx` and dumps every
tensor the C++ engine must reproduce. Offline Python only; `out/` is gitignored
(~800 MB) and regenerated by the script.

## Running

Same venv as `clip_test` (see its README), plus:

```bat
pip install onnx onnxruntime onnxscript
python C:\_stuffs\repo\2025.09\CUDA\python\export\export_clip.py
```

Options: `--batch N` (fixed batch baked into the graph, images cycled to fill it;
default one slot per image), `--opset`, `--out`, `--no-intermediates`.

## What it writes

| File | Contents | Use in C++ |
|---|---|---|
| `model.onnx` | the graph + weights (single file, weights as `raw_data`) | what the engine loads |
| `manifest.json` → `initializers` | name, shape, sum, abs_sum, first/last 8 values per weight | verify the protobuf parser read every weight correctly |
| `manifest.json` → `nodes` | every node in execution order: op, inputs, outputs, attributes | checklist for the executor walk |
| `tensors/NNNN_<name>.bin` | output of node NNNN | compare after every node; the first mismatch is the bug |
| `golden/pixel_values.bin` | `[N,3,224,224]` preprocessed images | graph input; also the week-5 preprocessing target |
| `golden/image_embeds.bin` | `[N,512]` | final output |
| `golden/text_embeds.bin` | `[L,512]` unit-length label embeddings | only to reproduce `test.py`'s probabilities |
| `golden/probs.bin` | `[N,L]` `softmax(logit_scale · img_unit @ text_unitᵀ)` | end-to-end label check |

All `.bin` files are raw little-endian, row-major, no header; dtype and shape are
in `manifest.json` (`tensors[name]` and `golden`). Images are processed in
**sorted filename order**, listed in `manifest.images`.

## How the reference is produced

- PyTorch model on CPU in **fp32** (no fp16, no TF32).
- Oracle: ONNX Runtime CPU with **all graph optimisations disabled**, so each
  intermediate is exactly one node's output, not a fused variant.
- ONNX Runtime output is checked against PyTorch `encode_image`; the script
  refuses to write goldens if they disagree.
- Exported with the dynamo exporter: ~480 nodes / 14 op types, versus ~990
  nodes with the legacy exporter (half of them runtime shape arithmetic).
